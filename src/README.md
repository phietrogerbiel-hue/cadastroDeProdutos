# Controle de Produtos

Uma aplicação Java desenvolvida para gerenciar o controle de estoque e cadastro de produtos.

---

## 📌 Sobre o Projeto

Este projeto tem como objetivo realizar o gerenciamento simples de produtos, permitindo funcionalidades como cadastro, atualização de estoque e remoção dos itens.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java 25
- **IDE:** IntelliJ IDEA
- **Gerenciador de Dependências:** Java Puro

---

## 🚀 Como Executar o Projeto

### Pré-requisitos

- Java JDK 25 ou superior instalado na máquina.
- Git instalado (opcional, para clonar o repositório).
